# Test Project

This is a test project for the productivity-kit plugin.

## Daily Journal & OKR System

| When | Skill | What |
|------|-------|------|
| Morning (Mon) | `/productivity-kit:okr-monday` then `/productivity-kit:good-morning` | Weekly goals + day start |
| Morning (Tue-Sun) | `/productivity-kit:good-morning` | Yesterday review + plan today |
| During day | automatic | Track activities in journal `## Notes` |
| Anytime | `/productivity-kit:journal` | Quick update |
| Friday | `/productivity-kit:okr-friday` | Celebrate wins, capture learnings |
