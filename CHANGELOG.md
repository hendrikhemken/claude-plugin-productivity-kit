# Changelog

All notable changes to the productivity-kit plugin.

## [1.0.0] - 2026-03-13

### Added
- Initial release
- 6 skills: setup, good-morning, okr-monday, okr-friday, journal, okr-expert
- SessionStart hook for automatic morning routine detection
- 6 templates for project initialization
- 11 OKR reference documents (Wodtke, Klau, Cagan methodologies)
- Mental Toughness framework (Hormozi) integrated into Monday/Friday check-ins
- Test project with example data
- Optional integrations: Google Calendar, Granola, GWS CLI/Gmail

### Methodology
- Based on Christina Wodtke's "Radical Focus" weekly rhythm
- Rick Klau's Google OKR grading system
- Marty Cagan's prerequisites check
- Alex Hormozi's Mental Toughness framework
